---
title: "Ray Display"
---

Choose whether traced rays appear as connected paths or individual interaction points. Color modes can show distance along a path, distinguish consecutive segments, identify interacting elements, or use one fixed ray color.

For any color mode other than **Solid Color**, choose a color map to change the ray gradient immediately.

Displaying fewer rays can keep large results responsive without changing the saved result. Maximum ray distance clips long paths around the scene for easier inspection.
