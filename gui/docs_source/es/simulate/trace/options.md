---
title: "Opciones de Trazado"
---

**Forma solar** muestrea el perfil angular de emisión configurado. Actívela para obtener una dispersión de flujo realista o resultados finales de rendimiento. Desactívela para usar una única dirección de entrada ideal, lo que resulta útil para comprobar la geometría, la alineación y el comportamiento óptico nominal.

**Errores ópticos** aplica los errores de pendiente y especularidad configurados para cada material. Actívelos para estudios de tolerancia y estimaciones realistas de rendimiento. Desactívelos para establecer una referencia ideal o aislar problemas de geometría y alineación.

**Depuración del trazador** está destinada a diagnósticos específicos del trazador cuando se investiga un problema y normalmente debe dejarse desactivada. El control actual está reservado para futuras funciones de diagnóstico y todavía no cambia el comportamiento del trazado.
